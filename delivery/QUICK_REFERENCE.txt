RISK MITIGATION (Top 3)
────────────────────────────────────────────────────────────────────────────────
Risk 1: terraform-proxmox-vm incomplete
  Impact:    Blocks all terraform repos (C)
  Mitigation: Verify in A-03 immediately; escalate if incomplete
  Contingency: Use Proxmox provider directly (no module)

Risk 2: Vault init JSON parsing fails
  Impact:    Unseal keys not captured; Phase 3 cannot unseal
  Mitigation: Test in B-05 Molecule tests; handle version differences
  Contingency: Manual key extraction + operator unseals manually

Risk 3: Operator skips unseal key backup
  Impact:    Vault unrecoverable if host lost
  Mitigation: Large warning text + clear operator runbook (F-02)
  Contingency: Recovery from external backup; Phase 6: implement KMS auto-seal
